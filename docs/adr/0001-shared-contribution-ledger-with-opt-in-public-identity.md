# Use one contribution ledger with opt-in public identity

KAD will keep one authoritative Contribution Ledger for work across Programs,
Events, Divisions, and Volunteer Cycles. An individual's ledger is a derived
view over shared Contribution Attributions rather than a separate copy, so one
collaborative outcome can credit several people without duplicating the work
record. Public identity is a separate opt-in projection; withholding a public
name does not remove the internal attribution, its evidence, or the
contributor-controlled ability to export verified work.
