# Project approved Discord activity through KAD-Agent

KAD-Agent and its Discord bot remain inside the private operational boundary
and become the future integration point for public Agenda records. The website
will consume a smaller approved projection rather than scrape Discord or read
the bot database directly. The first page revision will use deterministic
Preview Fixtures shaped like that projection; Agenda synchronization is the
first automation target, while Program metrics and Contributions remain
manually recorded and attested until later integrations are justified.
