# KAD staging reference coverage policy

- Cover every review direction at desktop and mobile widths.
- Keep the real navigation and destination context visible in each route.
- Capture the Field Notes production candidate separately from the two comparison directions.
- Record only repository-owned media and public, approved program evidence.
- A planning pass is not visual approval. Promotion requires captured PNGs and explicit human review.
- Reduced-motion, keyboard, overflow, and route behavior remain executable browser gates rather than screenshot-only claims.
